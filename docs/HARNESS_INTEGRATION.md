# DeepSeek Harness 可选引擎

已接入本地时序，直接 API 模式继续可用。在「AI 时间管家」选择「DeepSeek Harness」即可使用；沿用本次选择的 API。当前适配 DeepSeek / OpenAI Chat Completions 兼容接口，Anthropic 接口使用直接 API 模式。

## 固定版本

- Harness 版本：0.1.0-rc.5。
- 验证源码提交：47f943859bef60e4160492346772ded9b24f765a。
- 不修改独立 Harness 安装，不自动下载或更新运行时。
- 环境变量 HARNESS_ROOT 指向已经构建的源码目录。缺失、版本不同或产物缺失时，页面显示不可用，直接 API 不受影响。
- 迁移或开源安装：取得对应提交的 Harness 源码，按该版本说明安装依赖并 build，再配置 HARNESS_ROOT。容器部署需要在容器内提供运行时路径，不能直接使用 Windows 路径。

## 运行结构

harness/runtime.mjs 使用该版本 SDK 启动独立子进程，通过 stdio JSON-RPC 通信。每轮结束关闭进程，停止请求也关闭该进程。状态和实际文本增量经本地桥接回传，时序使用 NDJSON 将其流式传到浏览器。

每个时序对话映射为 shixu-对话ID。对应的独立工作目录、配置和原始会话日志位于 data/harness/workspaces 下；不读取用户独立 Harness 的项目、配置或密钥。时序聊天列表继续保存在 planner.sqlite 中。

rc.5 的 SDK 服务默认创建新会话，harness/sdk-plugin.mjs 是版本专用适配：沿用官方协议实现，发现已有会话时调用 agents.resume 恢复它。该适配覆盖了 rc.5 内部 createSession 扩展点，必须固定版本，升级前重新验证。

## 时序工具与保存

插件注册 runtime_info、web_search、web_read、shixu_query 和 shixu_apply。业务工具中，前者查询本轮最新暂存业务状态，后者提交结构化操作。工具沿用现有字段校验、课程冲突、日程冲突、截止时间检查。多个工具调用共享稳定的新记录 ID，允许后续查询、修改本轮创建的记录。

工具成功表示已校验并暂存。只有模型正常完成整轮、请求未取消且服务器 revision 未变化时，统一保存数据、聊天结果和撤销点。模型失败、输出截断、取消和跨设备并发冲突不会提交本轮暂存修改。修改后可使用对话里的撤销入口。

桥接服务只绑定本机回环地址，使用每次运行随机凭证。凭证不包含模型 API 密钥。模型密钥仅通过子进程环境提供，不写入生成的配置。联网工具可搜索公开网页并读取公开 HTTPS 文本；未挂载 shell、任意文件读写或操作已登录浏览器的工具。每轮最多 12 次模型请求、50 项业务操作，约 180 秒的运行上限。

## 数据与部署边界

现有业务 JSON 备份不含聊天库和 Harness 原始日志。完整迁移需备份整个 data 目录，并在目标机器配置兼容运行时；迁移运行时日志的路径兼容性仍需单独验证。删除聊天列表目前不会清理 Harness 原始日志。切换回直接 API 不删除已有数据。

已验证 Windows 下的真实进程启动、专用工具调用、文本流、原生会话恢复、取消后不提交，以及 HTTP 保存和撤销。模型服务使用本地测试接口，未以真实供应商请求验证推理效果；Android 实机、公开服务器、容器和 EXE 尚未验证。

## 联网和模型身份

runtime_info 返回配置中的服务商名称、模型 ID、引擎和工具列表，不含密钥。模型可直接告诉用户这些配置事实；不能保证第三方 API 的实际底层路由，也不应编造“型号保密”的规则。普通问答和学习讨论无需修改业务记录。

web_search 读取 Bing 公开搜索页面，无需额外搜索 Key；web_read 读取公开 HTTPS 文本。回答应引用来源链接，页面将 Markdown 来源渲染为可点击链接。搜索站点验证码、结构变化、无法访问或没有结果均报告失败，不使用伪造结果。纯 JavaScript 页面、需登录页面和 PDF 等非文本文件暂不支持。直接 API 模式没有联网工具，需选择 Harness。

网页读取固定 DNS 解析后的公网地址，逐次验证重定向，不传递登录 Cookie、模型密钥或时序账号。单网页最多 1.5 MB，正文最多 18000 字符，约 18 秒超时，每轮最多 12 次联网调用。网页文本按不可信资料处理，不作为执行日程修改的指令。公开搜索只提交工具选择的查询词，不自动上传全部日程。

本机已实际验证公开搜索和 DeepSeek 官网文本读取。自动测试使用固定网页样本验证解析与网络范围控制，真实 Harness 测试验证新工具注册和 runtime_info 调用。


### Windows 隐藏启动

时序通过 `harness/hidden-client.mjs` 在独立 Worker 中加载 SDK，仅在该 Worker 内为 `child_process.spawn` 添加 `windowsHide: true`，兼容 SDK rc.5 缺少隐藏窗口参数的问题。服务器主线程和独立 Harness 安装不受影响。仍由 SDK 负责关闭和回收子进程；取消、历史恢复和工具写入使用原有协议。
