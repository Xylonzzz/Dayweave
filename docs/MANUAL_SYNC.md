# 本地优先与手动同步

## 使用

1. 在设置进入本地模式。首次可创建空白空间，或选择复制当前服务器数据；已有本地空间不会被覆盖。
2. 在「手动同步」中展开连接表单，填写目标服务器地址及其账号密码。远程地址须为 HTTPS，本机可用 localhost。目标也需要升级到支持同步协议的时序版本。
3. 连接成功后点击「预览数据差异」。连接只获取授权，不上传日程；密码不保存在浏览器，同步令牌保存在此浏览器的本地空间。
4. 选择合并双方修改、以本地为准或以服务器为准。合并按上次成功同步的共同版本判断；首次没有共同历史，只合并双方独有条目，不推断删除。
5. 同一条记录被两端分别修改，或一边删除另一边修改时，逐条选择保留本地或服务器版本。预览会列出新增、修改、删除和前后内容。覆盖模式会移除另一方独有数据，请核对后勾选确认。
6. 确认后写入。网络中断时保留待确认记录，刷新后点击「重试待确认同步」。服务器保留回执，同一请求即使已成功也不会重复写入。

默认不自动上传。日常本地编辑和断网保存不依赖服务器；页面关闭后不会自动同步。可保存多个服务器连接，每个目标分别保留授权和共同版本；更换目标后需要重新预览。

## 数据范围与恢复

- 同步课程、任务、日程、灵感、复盘和业务偏好。作业完成与提交、实际提交时间保持区分。
- 账号、模型 API 密钥、聊天库、通知订阅、本设备外观与灵感气泡偏好不参与同步。AI 在本地模式仍需另行接入服务，当前同步连接不承担 AI 转发。
- 本地及服务器各保留一个同步前恢复点。本地通过「数据与账号」下载本地恢复点；服务器通过同步卡片下载恢复点。恢复文件先导入预览，不自动回滚另一端；恢复后再次同步仍需确认差异。
- 同步等待期间可以继续编辑。本地的新修改会保留，冲突时保留等待期间的本地修改，并在下一次同步预览中处理。
- 预览后本地或服务器发生新修改时，会要求重新预览。同步不会自动重排日程，合并后仍可人工调整安排。
- 删除通过每个设备和服务器的共同快照识别。已有共同历史的单边删除不会复活；没有共同历史的新连接无法区分「从未同步」和「曾经删除」，首次合并应检查旧数据是否需要保留。

完整服务端备份可运行 `npm run backup:local`，将在线数据库一致性快照和解密密钥存入数据目录下的 `backups/`，并检查数据库完整性。它保留聊天库、账号和 API 配置，不包含程序代码、外部 Harness 或浏览器本地空间。备份包含个人数据和解密密钥，不应分享或放入公开仓库；恢复方法见备份中的 RESTORE.txt。

## 协议边界

独立 `/api/sync/v1` 接口使用绑定来源的专用 Bearer 令牌，不能以浏览器登录 Cookie 授权，也不能操作 AI 接口或开发工具。同步授权有效期 30 天；断开连接时撤销，服务器修改账号密码也会使旧授权失效。跨域同步显式省略 Cookie，拒绝跳转；首次连接先检查协议，再向所选地址提交账号密码。浏览器 CSP 允许 HTTPS 和本机同步连接。

当前每个服务实例限制 100 个有效同步授权和 100 个同步设备回执；单请求上限 2 MB。一个本地空间同时只确认一个目标的同步，避免多标签页或多服务器并发写入。此版本是单用户自托管同步，尚不是多人账号系统。

## 验证范围

单元/API 测试覆盖三方合并、首次冲突、删除与修改、自定义类型、提交时间、令牌来源隔离、过期撤销、旧版本拒绝、重复回执和无效数据不写入。真实 Edge 浏览器使用独立测试服务器和两个浏览器空间验证跨来源连接、确认前不写入、冲突选择、回复丢失、服务器重启、刷新后重试、等待期间本地编辑保留及删除同步。

Android 实机、公网 HTTPS、移动网络、跨版本兼容和大规模数据尚需后续验收。自动同步尚未启用。
