# 智能录入草稿

“跟 AI 说”默认开启智能补全，发送用户描述、作息、课表、现有待办及未来日程，模型据此推断类型、课程/项目、重要性、时间和预计耗时。地点、链接和关联任务没有依据时可以留空，不能编造。

智能补全一律先预览，不因字段完整而自动保存。预览可修改任务类型、所属课程/项目、预计耗时、重要性、紧急性、截止日期/钟点、提交链接、活动关联任务、地点、锁定状态、时间与备注。服务端仍校验时间、冲突和草稿版本。

assumptions 是模型提供的暂估字段及理由，evidence 是模型声称的输入/上下文依据，均需用户核对，不是事实验证。推断截止钟点仅为提醒暂定值，不代表教师或平台要求。暂估说明随保存备注保留。若模型遗漏依据，智能草稿会显示整体核对提示。

关闭智能补全后继续使用严格提取方式，不足的钟点需要补充。该功能目前需要服务器及所选在线 AI；本地离线模式尚不能调用 AI。测试使用模拟模型验证交互及保存，不能证明真实模型在所有描述中正确理解意图。
