# 日历、AI 对话与导航排序

日历支持日、周、月、年四种视图，统一读取课程、日程和任务截止时间。点击年历里的月份进入月历，点击日期进入当日时间轴；日期选择器和左右箭头可切换日期。切换尊重系统的减少动态效果设置和应用动画开关。

设置中的「我的空间 · 导航顺序」使用上下按钮即时保存。服务器模式随业务数据保存，本地模式保存在当前浏览器的本地空间。

「AI 时间管家」是独立对话页，使用已配置的 API。发送消息表示授权执行该消息要求的业务操作。支持课程、任务、日程、灵感、复盘和偏好的查询、新增、修改与删除；偏好只能修改。模型看不到账号密码和 API 密钥，也没有 shell、文件系统或外部网站操作工具。本地模式目前不提供联网 AI。

服务端读取最新业务数据和最近 20 条对话，将模型返回的结构化操作统一验证后原子保存。版本发生变化时拒绝保存。日程变更检查关联任务、截止时间、课程和日程冲突。删除任务会解除日程关联，保留日程。实际提交必须包含提交时间。自定义类型、复盘和导航顺序均经过既有验证器。

聊天记录和项目保存在服务器 SQLite 的 chatWorkspace 中，支持新建、重命名、删除、移入项目和刷新后恢复。项目说明用于该项目内对话的背景；不同对话不自动共享聊天全文。每次请求使用本对话最近 18 条有效历史和当前输入，长历史不会全部发送给模型。业务数据 JSON 备份暂不包含聊天库，完整迁移聊天需保留服务器数据库。

最近一次 AI 修改有持久化恢复点，但只有此后没有其他数据修改时才能直接撤销。对话保留对应撤销入口，撤销结果也进入历史。停止请求存在响应已完成的竞态，因此停止后应核对数据再重试。模型返回 assumptions/evidence 字符串或字符串列表时，作为推断/依据显示；任务与日程还会写入备注。其他未知字段仍会报错，避免静默丢失业务字段。

测试使用模拟模型，验证真实 HTTP 保存、撤销与浏览器流程，不代表任何特定供应商的真实推理质量或速度。

可选 Harness 引擎已接入，配置和验证范围见 HARNESS_INTEGRATION.md。
