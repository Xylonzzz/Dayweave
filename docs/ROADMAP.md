1. 同步实机试用：Windows 与 Android、HTTPS 自托管、断网恢复、大数据和升级兼容。自动同步已有本地浏览器验证，仍需实机与公网验收。

4. 干净电脑与 Android 验收：完整安装、UAC、重启续接、提醒、离线与换服务器。
5. 开源测试版：用户选择许可证、完整秘密检查、贡献与兼容说明、发布包和自动测试。官方升级不能静默覆盖用户定制。

聊天库跨端同步、远程开发产物分发和 EXE 自动更新不属于手动同步实现；多用户共用服务器由账户隔离阶段补充。
