# 本地与离线模式（第一阶段）

## 使用

1. 在线打开时序，在登录页选择“无需登录，使用本地空间”，或在设置的“数据存储模式”进入。
2. 首次可创建空白空间，或明确选择复制当前已加载的服务器数据。已有本地空间不会被复制操作覆盖。
3. 在设置点击“准备 / 更新离线资源”，等待成功提示。此后同一浏览器、同一网址可断网刷新或重新打开。
4. 手动任务、课程、日程、灵感、四象限、复盘与 JSON 备份在本地保存。AI、文件识别和推送暂需服务器模式，不属于完全离线能力。
5. 返回服务器模式不会上传本地修改。真正的合并、同步目标选择和冲突处理属于下一阶段，当前不要用切换模式代替同步。

## 数据边界

- IndexedDB 保存本地数据；事务完成后才返回成功。版本检查阻止旧窗口覆盖新数据。
- 浏览器配置文件及网址隔离本地空间。Edge 与其他浏览器、localhost 与 127.0.0.1、不同端口不共用本地数据。
- 清除网站数据、使用隐私模式或浏览器回收存储可能丢失本地内容。应用会请求持久存储，但浏览器可拒绝；请定期导出 JSON 文件。
- 导入先预览并确认，原数据在同一事务中保留一个恢复点；可下载恢复点再导入。
- 本地空间没有独立应用密码，也不复制服务器账号、API 密钥。设备使用者可通过此浏览器访问本地数据。
- Service Worker 仅缓存公开程序资源，不缓存任何 /api 响应。首次启动或资源下载未完成时不能保证离线打开。
- 浏览器版离线能力不等于 Windows exe。桌面封装在可选同步与冲突处理完成后进行。

## 验证

浏览器测试覆盖断网刷新、创建任务和灵感、新标签页重新打开、IndexedDB 版本冲突、备份恢复点、缓存不含 API，以及复制/切回模式不上传、不覆盖已有本地空间。实机 Android 和 exe 尚未验证。
